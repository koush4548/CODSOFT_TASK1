CloudVault is a cloud-based web application for uploading, previewing, and managing digital files, developed as part of the CodSoft Cloud Computing Internship (Task 1).

🚀 Key Features
Cloud Object Storage Ready: Configured for S3-compatible cloud bucket storage with real-time storage quota tracking.

Fast File Ingestion: Drag-and-drop upload zone supporting parallel multi-part transfers, live streaming progress bars, and transfer speed meters.

Complete File Operations: Secure upload, in-app file preview, instant download, metadata tagging, starring, and deletion with confirmation dialogs.

Dynamic Asset Categorization: Fast filter tabs across All Files, Images, Documents, Media, and Code with live search indexing.

Shareable Links: Generates quick shareable download links for stored assets.

Modern Minimalist UI: Built with a clean, high-contrast white layout.

🛠️ Tech Stack
Frontend: React, Tailwind CSS, Lucide React Icons

Storage & State: S3-compatible cloud storage architecture / Local client persistence

Design System: Clean white minimalist UI

💻 Getting Started
Clone the repository:
git clone https://github.com//CODSOFT_TASK1.git
cd CODSOFT_TASK1

Install dependencies:
npm install

Run the development server:
npm run dev
